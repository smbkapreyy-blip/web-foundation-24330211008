 *2. Snapchat
* ** URL:  https://www.Snapchat.com
* ** Method: GET
* ** Status Code: 200 OK
* ** Content-Type: text/html; charset=utf-8


* Request
* HTTP Request dalam Snapchat adalah perintah atau pesan digital yang dikirimkan oleh aplikasi Snapchat di ponsel Anda ke server pusat Snapchat untuk meminta data atau melakukan tindakan tertentu.

*Response
*Secara teknis, HTTP Request dalam Snapchat adalah jembatan komunikasi berupa pesan digital yang dikirim oleh aplikasi Snapchat di HP Anda menuju server pusat Snapchat. Karena Snapchat adalah aplikasi yang sangat dinamis dan berbasis real-time, hampir setiap ketukan, geseran, atau pengiriman pesan yang Anda lakukan memicu satu atau beberapa HTTP Request di balik layar.

*3. Grab

* ** Content-Type: text/html; charset=UTF-8



* Request
* HTTP Request dalam Grab adalah pesan atau perintah digital yang dikirimkan oleh aplikasi Grab di ponsel Anda (baik aplikasi penumpang maupun pengemudi) ke server pusat Grab untuk meminta informasi atau melakukan suatu aksi.

*Response
*Secara teknis, HTTP Request dalam Grab adalah jembatan komunikasi berupa pesan digital yang dikirim oleh aplikasi Grab di HP Anda (penumpang atau pengemudi) menuju server pusat Grab. Karena Grab adalah aplikasi layanan on-demand yang berbasis lokasi dan waktu nyata (real-time), setiap ketukan atau perubahan di layar HP Anda akan langsung memicu HTTP Request agar layanan bisa berjalan.
